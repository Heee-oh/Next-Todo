# NextStep — Only Next Day Todo

내일의 계획을 세우고, 오늘은 계획대로 실행만 하는 미니멀 데스크톱 투두 앱입니다. **오늘 할 일은 수정할 수 없고, 오직 내일의 할 일만 추가·수정**할 수 있다는 단순한 규칙으로 매일 계획하는 습관을 돕습니다.

## 📌 핵심 규칙
- 오늘은 실행만: 이미 결정된 오늘의 투두는 수정·추가가 불가합니다.
- 내일은 설계: 모든 추가·편집은 “내일” 목록에만 가능합니다.
- 매일 반복: 자정마다 내일의 계획이 오늘의 작업으로 자동 전환되는 흐름을 지향합니다.

## ✨ 주요 특징
- **집중력 향상**: 오늘은 계획 고민 없이 실행에만 집중하도록 설계.
- **습관 형성**: 매일 “내일”을 설계하도록 유도해 계획 루틴을 만듭니다.
- **Electron + React**: 데스크톱 환경에서 빠르게 실행할 수 있는 기술 스택.

## 🚀 빠른 시작
> Node.js 14+ 및 npm이 설치되어 있어야 합니다.

```bash
# 1) 의존성 설치
npm install

# 2) 개발 모드 실행 (React + Electron 동시 실행)
npm run dev
```

### 기타 스크립트
| 명령어 | 설명 |
| --- | --- |
| `npm start` | React 개발 서버 실행 |
| `npm run electron` | Electron 프로세스 실행 |
| `npm run build` | React 정적 빌드 생성 |
| `npm run dist` | 배포용 실행 파일 빌드 |

## 🗂️ 프로젝트 구조
- `public/electron.js` – Electron 메인 프로세스
- `public/index.html` – 기본 HTML 템플릿
- `src/index.js` – React 진입점
- `src/App.js` – 메인 UI 컴포넌트
- `src/App.css`, `src/index.css` – 스타일 시트

## 🎯 제품 철학
- **미래 중심**: 과거·현재의 후회 대신 “내일 무엇을 할지”에 집중.
- **제한을 통한 자유**: 오늘을 수정할 수 없는 제약이 오히려 실행력을 높입니다.
- **계획 → 실행 사이클**: 매일 밤 내일을 설계하고, 다음 날엔 흔들림 없이 실행.

## 🛣️ 로드맵

- 플로팅 UI 및 “항상 위” 모드
